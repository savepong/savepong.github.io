เรื่องมันเริ่มจากความน่ารำคาญเล็ก ๆ ครับ ผมใช้ AnyDesk free tier รีโมทจาก MacBook ที่บ้านเข้า iMac ที่ออฟฟิศ แล้วมันจำกัด session แถมเตือนเรื่อง "commercial use" เป็นระยะ

ทางที่เร็วที่สุดคือไป patch ไบนารีมันให้ปลดลิมิต — ซึ่งผม **ไม่ทำ** เพราะมันผิด license ชัด ๆ เลยเลือกทางที่ยาวกว่าแต่ถูกกติกา: ไปทำความเข้าใจก่อนว่าฟีเจอร์ที่ผมอยากได้ "มันทำงานยังไง" แล้วหาของที่ทำแบบเดียวกันได้โดยไม่ต้องแหกกฎ

## เปิดฝาดูเครื่องยนต์ก่อน

ผมเอา AnyDesk บน macOS มาส่อง (แบบ read-only นะครับ ไม่ได้แก้อะไร) ด้วย REA + Ghidra เป้าหมายไม่ใช่การแคร็ก แต่คืออยากรู้ว่าฟีเจอร์ "Privacy Mode" ที่ทำให้จอฝั่งออฟฟิศดำ แต่ผมยังเห็นภาพอยู่ มันเสกออกมาได้ยังไง

คำตอบง่ายกว่าที่คิดเยอะครับ: มันไปเซ็ต **gamma ของจอเป็น 0**

เปรียบเทียบง่าย ๆ เหมือนกล้องวงจรปิดในห้อง แล้วเราปิดไฟในห้องทิ้ง คนที่เดินเข้ามามองไม่เห็นอะไร แต่สัญญาณที่ส่งออกไปยังชัดอยู่ เพราะการ "ปิดไฟ" ถูกใส่ *หลัง* ขั้นตอนจับภาพไปแล้ว การจับภาพไม่ได้สนใจว่าจอจริงสว่างหรือดำ

พอรู้แก่นแบบนี้ ผมไปเปิดซอร์สของ RustDesk ดู แล้วเจอว่ามันใช้ **เทคนิค gamma เดียวกันเป๊ะ** ในไฟล์ฝั่ง macOS ของมันเอง — สรุปตรงนั้นเลยว่าไม่มีเหตุผลต้องเขียนแอปใหม่ ของที่ต้องการมีอยู่แล้ว แล้วมันเป็น AGPL ด้วย

## setup ที่ลงตัว

- **ท่อเชื่อมคนละเน็ต: Tailscale** ไม่ต้องไป port-forward เราเตอร์ ไม่ต้องพึ่ง public server ของใคร สองเครื่องเป็นของผมเองอยู่บน tailnet ส่วนตัว
- **ช่องทางหลัก: SSH** เพราะงานจริง 90% คือ "เข้ามาเช็คงาน" ไม่ได้ต้องการเห็นหน้าจอ ข้อดีที่ผมชอบมากคือจอที่ออฟฟิศไม่ถูกแตะเลย ยังล็อกอยู่ ยังดำอยู่ — ได้ privacy ฟรีโดยไม่ต้องตั้งอะไรเพิ่ม
- **ช่องทางรอง: RustDesk** เปิด service standby ไว้ ใช้ตอนที่ต้องเห็น GUI จริง ๆ แล้วกด Privacy Mode เพื่อให้จอฝั่งนั้นดำ

ประเด็นที่ผมว่าสำคัญกว่าตัวเครื่องมือ: อย่าเอา GUI ไปทำงานที่ terminal ทำได้ดีกว่า เบากว่า ปลอดภัยกว่า และพังน้อยกว่าเยอะครับ

## gotcha ที่กินเวลาผมไปเป็นชั่วโมง

ถ้าคุณจะไปแตะ remote control บน macOS อ่านตรงนี้ก่อน

**"ต่อติดแต่คุมเมาส์คีย์บอร์ดไม่ได้"** — อันนี้คลาสสิกเลย สาเหตุคือสิทธิ์ Accessibility (และมักจะต้อง Input Monitoring ด้วย) ยังไม่ครอบ process ที่ทำหน้าที่ฉีด event ให้ reset สิทธิ์แล้วให้ใหม่ผ่าน prompt ของแอปเอง แล้ว reboot

**"พิมพ์ไปแล้วเงียบหายทั้งหมด"** ตอนที่จอฝั่งปลายทางหลับอยู่ — อันนี้สนุกครับ เพราะเป็นจุดที่งาน RE ให้คำตอบตรง ๆ AnyDesk มันเรียก API ที่ *ปลุกจอให้ตื่น* ทุกครั้งที่มี input เข้ามา ส่วน RustDesk ถือแค่ "assertion กันจอหลับ" แบบ passive แปลว่าถ้าจอหลับไปก่อนแล้ว event ที่เราฉีดเข้าไปจะถูกทิ้งเงียบ ๆ ไม่มี error อะไรเลย ทางแก้คือใช้ Privacy Mode (จอยัง active) หรือกันจอหลับด้วย caffeinate

**"ไฟล์ config แก้แล้วไม่ติด"** — เพราะ background service มันเขียนทับไฟล์นั้นตอนสตาร์ท ต้องตั้งผ่าน GUI ขณะ service รัน ไม่ใช่ไปแก้ไฟล์ตรง ๆ

**sshd บน macOS เป็น socket-activated** เลยไม่โชว์ใน `lsof` แม้ Remote Login เปิดอยู่ อย่าเพิ่งตกใจ เช็คด้วย `nc -z <host> 22` แทน

**passwordless SSH ไม่ทำงาน** ก็มักเป็นเรื่อง permission ของ private key ฝั่ง client — ถ้า key เป็น 0644 ssh มันจะเมินให้เลย แก้ด้วย `chmod 600`

บทเรียนรวบยอดของผมคือ การเสียเวลาไปเข้าใจว่า "ของเดิมมันทำงานยังไง" ไม่ใช่การเสียเวลาครับ มันทำให้ตอนที่ของใหม่พังแบบเงียบ ๆ ผมเดาถูกตั้งแต่ครั้งแรก
